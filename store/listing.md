## 詳細說明

以下整段貼上（商店欄位為純文字，不支援 Markdown）：

```
YouTube 關閉瀏覽器後還原的是網址，而網址通常不含時間參數，重新打開影片就從 0:00 開始。這支擴充功能把觀看進度存在瀏覽器本機，重新打開同一支影片時接續上次的位置。

功能
・播放時每 2.5 秒記錄一次進度，暫停、換片、切換分頁時補寫
・重新打開影片後自動接續，左下角顯示接續的時間點，可選擇從頭播放
・工具列面板列出最近的觀看記錄，點擊即從該時間點開啟
・廣告播放期間不記錄，避免廣告秒數覆蓋正片進度
・距離片尾 20 秒內視為看完，下次不會被拉回結尾
・網址自帶 t= 時以網址為準
・工具列面板可切換記錄功能的開關

資料存放
記錄存在瀏覽器的本機儲存空間（chrome.storage.local），不會上傳，也沒有分析或追蹤程式碼。

權限
storage：儲存影片 ID 與觀看秒數。內容腳本只在 youtube.com 上執行。

開源
原始碼與問題回報：https://github.com/xygowo/youtube-resume-helper
授權：MIT
```

## 權限理由

| 權限 | 填寫內容 |
| --- | --- |
| `storage` | 儲存影片 ID、觀看秒數與影片標題，用於續播與工具列面板的記錄清單。資料只存在使用者裝置，不會傳送出去。 |

沒有主機權限，內容腳本僅在 `youtube.com` 執行。

## 常見退回原因

- 權限說明寫得太籠統（例如只寫「需要 storage 才能運作」）
- 單一用途描述包含多個不相關的功能
- 截圖含有其他品牌的商標或無法辨識的內容
- zip 內含測試檔、node_modules 或 `.git`
- 版本號沒有遞增就重新上傳
