## 詳細說明

上限 16,000 字元。

```
关闭浏览器后，浏览器还原的是网址，而 YouTube 的网址通常不含时间参数，重新打开就从 0:00 开始。这个扩展程序把观看进度存在浏览器本地，重新打开同一支视频时继续上次的位置。

功能
・播放时每 2.5 秒记录一次进度，暂停、换片、切换标签页、关闭页面时补写
・重新打开视频后自动跳回上次的位置，左下角显示提示，可选择从头播放
・工具栏面板列出最近的观看记录（缩略图、进度、上次观看时间），点击即从该时间点打开
・广告播放期间不记录，避免广告时间覆盖正片进度
・距离片尾 20 秒内视为看完并清除记录，下次不会被拉回结尾
・网址自带 t= 或 start= 时以网址为准
・拖动进度条或点击播放器后，本次续播立即取消
・工具栏面板可切换记录功能的开关

数据存放
记录存在浏览器的本地存储空间（chrome.storage.local），不会上传，也没有分析或追踪代码。

权限
storage：保存视频 ID 与观看秒数。内容脚本只在 youtube.com 上执行。

开源
源码与问题反馈：https://github.com/xygowo/youtube-resume-helper
许可证：MIT
```
